🐾 SOS Peludinhos - Sistema de Gestão Veterinária
Um sistema desktop desenvolvido em Java para o gerenciamento integral de uma clínica veterinária. A aplicação foca na usabilidade e na consistência dos dados, permitindo o controle eficiente de tutores, pacientes e histórico de agendamentos, com persistência em um banco de dados relacional.

Este projeto foi construído com foco na aplicação prática de Programação Orientada a Objetos (POO) e arquitetura de software, estruturando a comunicação entre a interface visual e o banco de dados através do padrão DAO (Data Access Object).

🚀 Funcionalidades
Gestão de Clientes: Cadastro e manutenção da base de tutores da clínica, permitindo visualização em listagem dedicada.

Controle de Pacientes: Registro detalhado de animais, estabelecendo vínculo relacional direto com seus respectivos tutores.

Módulo de Agendamentos: Interface específica para marcação, registro e acompanhamento de consultas e atendimentos veterinários.

Visualização Modular: Telas de listagem independentes para rápida consulta e filtragem de clientes, pets e atendimentos já cadastrados no sistema.

🛠️ Tecnologias e Arquitetura
Linguagem: Java

Interface Gráfica: Java Swing (componentes customizados e navegação entre telas)

Banco de Dados: Microsoft SQL Server

Integração: JDBC (Java Database Connectivity)

Arquitetura: Padrão estrutural em camadas (Model, View, Controller/DAO) para separação clara de responsabilidades entre regras de negócio, interface e persistência.

⚙️ Como Executar Localmente
Pré-requisitos
Java Development Kit (JDK) instalado.

Microsoft SQL Server instalado e rodando.

Driver JDBC do SQL Server (mssql-jdbc.jar).
